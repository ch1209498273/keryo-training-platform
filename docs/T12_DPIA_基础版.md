# DPIA 个人信息保护影响评估（基础版）（T-12.2）

> 依据：GB/T 35273-2020《个人信息安全规范》、PIPL（个人信息保护法）
> 编制时间：2026-08-07

## 1. 个人信息清单

| 数据项 | 字段 | 敏感级别 | 收集途径 | 保存位置 |
|--------|------|----------|----------|----------|
| 姓名 | el_sys_user.real_name | 一般 | 管理员批量导入/注册 | MySQL |
| 手机号 | el_sys_user.mobile | 一般（可识别）| 同上 | MySQL |
| 登录账号 | el_sys_user.user_name | 一般 | 同上 | MySQL |
| 密码哈希 | el_sys_user.password | 敏感 | 用户设置 | MySQL（bcrypt）|
| 科室归属 | el_sys_user.dept_code | 一般 | 导入 | MySQL |
| 培训成绩 | el_exam_record.* | 一般（职业发展相关）| 系统生成 | MySQL |
| 审计日志 | el_keryo_audit_log | 一般 | 系统生成 | MySQL |
| 考试作答 | el_paper_qu | 一般 | 用户答题 | MySQL |
| AI 服务密钥 | el_keryo_ai_config.api_key | 敏感 | 管理员配置 | MySQL（界面脱敏回显）|

## 2. 数据处理目的与合法性

| 处理活动 | 目的 | 合法性基础 |
|----------|------|------------|
| 收集学员信息 | 培训管理（注册/登录/成绩）| 劳动合同/内部管理规定（中心与员工）|
| 成绩记录 | 培训效果评估 | 用人单位管理需要 |
| 审计日志 | 安全审计、防抵赖 | 网络安全法要求 |

## 3. 风险分析

| 风险 | 可能损害 | 可能性 | 严重性 | 缓解措施（已实施）|
|------|----------|--------|--------|-------------------|
| 密码泄露（暴力破解）| 账号被冒用 | 中 | 中 | bcrypt 哈希、失败锁定、图形验证码 ✅ |
| 越权访问他人成绩 | 隐私泄露 | 低 | 中 | RBAC + data_scope + 权限注解 ✅ |
| 审计日志泄露 | 个人行为被非法利用 | 低 | 低 | PII 脱敏存储、日志不可删 ✅ |
| 数据库备份泄露 | 全量数据泄露 | 低 | 高 | 备份 AES-256 加密 ✅ |
| 前端展示泄露 | 围观窥屏 | 中 | 低 | 姓名脱敏（张*）✅ |
| 离职人员数据保留 | 过度收集 | 中 | 低 | 数据保留策略（T-12.3）✅ |

## 4. 数据主体权利

| 权利 | 现状 | 说明 |
|------|------|------|
| 知情权 | ✅ | 系统内公示用途（部署时告知）|
| 查询/更正 | ✅ | 用户设置页可改个人资料 |
| 删除 | ⚠️ | 管理员可删除账号（培训记录保留策略约束）|
| 撤回同意 | ⚠️ | 内部管理场景适用劳动合同例外 |

## 5. 结论

**基础版评估通过**：当前处理活动符合"用人单位内部管理"合法基础，已实施中等强度安全措施（bcrypt/权限/脱敏/加密备份），残余风险可接受。**M2 补充**：正式隐私告知文本、删除权流程确认。

# 数据保留策略（T-12.3）

| 数据类型 | 保留期限 | 到期处理 | 依据 |
|----------|----------|----------|------|
| 培训记录（考试/成绩）| **≥3 年** | 归档后删除（管理员操作）| 卫生行业培训档案要求 |
| 学员账号 | 离职后 1 年 | 停用（state=DISABLED）| 内部管理规定 |
| 审计日志 | **≥1 年** | 不可删（触发器保护），满期归档 | 网络安全法第 21 条 |
| 备份文件 | **7 天滚动** | 自动清理（backup_db.sh）| 备份策略 |
| 考试会话数据（el_paper）| 1 年 | 归档清理 | 成绩已固化于 el_exam_record |
| 题目/培训内容 | 长期 | 保留 | 知识资产 |
