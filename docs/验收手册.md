# 血透中心医护培训平台 · 验收手册

> 版本：v2.1（+ 成绩公示 T-15、取消学分 T-16、AI 配置 T-17）
> 验收对象：yf-bev2 后端 + yf-bev2-vue 前端
> 数据库：exam_keryo（MySQL 8.4）

---

## 一、系统概述

面向集团多中心的**培训-考试一体化平台**，覆盖：题库建设与审核、考试组卷与在线答题（防切屏）、培训内容学习、培训计划排课与审批、管理看板（通过率/参训名单）。

**核心设计**：
- 7 种角色，按 **数据范围**（本人/本科室/区域/全量）隔离数据
- 一个培训计划对应一个培训内容（原课件），**只有参与该计划的学员可见**
- 成绩修正权限**仅总监**；助理可建题但**需督导/总监审核**
- 已取消练习功能

## 五、分模块验收清单

### 5.1 登录与基础安全 【T-01/T-02/T-07】

- [ ] 访问 `http://localhost:8000`，显示登录页 + 图形验证码
- [ ] 验证码错误 → 登录失败；验证码正确 + 正确账号密码 → 登录成功
- [ ] 连续输错验证码/密码不会被绕过
- [ ] 登录后 URL 地址栏有 `token`（token 鉴权）
- [ ] 退出登录后 token 失效，无法再访问接口
- [ ] 密码以 **bcrypt** 存储（数据库 `el_sys_user.password` 为 `$2y$10$...`，非明文/MD5）
- [ ] 登录/操作有**审计日志**（`el_keryo_audit_log` 表可查）
- [ ] 响应头含安全头（X-Content-Type-Options、X-Frame-Options 等）
- [ ] 不登录直接访问业务接口 → 401/403

### 5.2 系统配置（仅超管 admin）【T-01/T-17】

- [ ] admin 能看到：菜单管理、角色管理、数据字典、个性配置、插件管理
- [ ] 菜单管理：可维护菜单树（增删改排序）
- [ ] 角色管理：可建角色、分配菜单权限（按钮级）
- [ ] 数据字典：可维护字典项（题型、难度等）
- [ ] **其他角色看不到「系统设置」菜单**（登录 rev1/student 确认）
- [ ] **AI 设置**（T-17，仅 admin）：
  - [ ] 「系统设置 → AI 设置」可进入，服务商下拉可选：DeepSeek/通义千问/OpenAI/Kimi/智谱/自定义
  - [ ] 选模板自动填充接口地址与模型名；填入 API Key 后可「测试连接」→ 显示连接成功/失败
  - [ ] 保存后回显 Key 为脱敏形式（如 `sk-***f0e9`），不完整显示
  - [ ] Key 留空保存 = 不修改原 Key
  - [ ] 非 admin 角色访问 AI 设置接口 → 403（`sys:ai-config:view/edit`）

### 5.3 组织架构（超管/助理）【T-01】

- [ ] admin 与助理可见「组织架构 → 部门管理/人员管理」
- [ ] 部门管理：多中心 + 集团结构（KERYO → KERYO_C01~Cnn）
- [ ] 人员管理：可新增用户、分配角色、启用/禁用
- [ ] 督导/医护长/学员**看不到**组织架构菜单

### 5.4 题库管理（总监/助理/督导/超管）【T-04】

- [ ] 建题：支持单选/多选/判断/填空/简答五类题型，可设置分数、难度、解析
- [ ] 建题后状态为 **DRAFT（草稿）**
- [ ] 审核流程：一审通过 → REVIEW2 → 二审通过 → **APPROVED（可被抽题）**
- [ ] 驳回 → 回到草稿，可修改后重新提交
- [ ] **不可审核自己创建的题目**（助理建题必须督导/总监审；总监/督导/超管可审自己）
- [ ] 只有 APPROVED 的题才会被组卷抽中
- [ ] **医护长看不到题库管理菜单**
- [ ] **学员看不到题库管理菜单**

### 5.5 考试管理（组卷：总监/助理/超管；查看成绩：+督导/医护长）【T-05】

- [ ] 新建考试：填标题、时长、及格分，配置组卷规则（题型×数量×分数）
- [ ] 从题库按规则随机抽题组卷
- [ ] 查看/修改/删除考试
- [ ] 考试管理页能看到「考试记录」入口
- [ ] **成绩修正（edit-score）仅总监 nurse_head 可见可用**：
  - [ ] 总监在考试记录中可修正学员分数（记录锁定后也可改，自动解锁）
  - [ ] 修改分数后「通过/未通过」按及格分自动重算
  - [ ] 助理/超管/学员**没有**成绩修正入口，直接调接口被拒
- [ ] **补考（retry，管理端发起）**：
  - [ ] 总监/管理员在考试记录中对已考学员点【补考】→ 该学员考试次数重置
  - [ ] 学员刷新「在线考试」→ 可再次进入重考（交卷后自动拦截已阻止重复进入）
  - [ ] 补考保留历史成绩，交卷后按新成绩更新最近分/通过状态
  - [ ] 无 `exam:record:retry` 权限的角色调 `/retry` 被拒
- [ ] **成绩公示（T-15）**：
  - [ ] 考试表单有「交卷后公布成绩」开关（默认关闭 = 不公示）
  - [ ] 考试管理列表有「成绩公示」列：待公布 / 已公布
  - [ ] 点【公布成绩】→ 学员端交卷结果页/考试记录立即可见分数与通过状态
  - [ ] 点【收回】→ 学员端重新隐藏分数（管理端仍可见真实成绩）
  - [ ] 未公示时学员直接调 `/paper/detail`、`/full-detail` 拿不到分数（管理端角色放行）
- [ ] **医护长**：可见考试管理（看本科室成绩），**无添加/编辑/删除考试按钮**（不能组卷）
- [ ] **督导**：可见考试管理（看区域成绩），无组卷按钮

### 5.6 培训管理（原课件，总监/助理/超管）【T-03/T-13】

- [ ] 管理端菜单名为「**培训管理**」（不再是课件管理）

### 5.7 培训计划（排课+审批+学员参与）【T-06/T-13】

## 六、端到端主流程验收（按顺序做一遍）

### 场景 A：培训学习闭环
1. `admin` 登录 → 培训管理 → 上传一个 PDF → 记录培训标题
2. 培训计划 → 新建计划（关联刚上传的培训、可选关联考试）→ 提交审批
3. 换 `rev1` 登录 → 审批通过
4. `admin` → 培训计划 → 分配学员 → 把 `student` 分配进该计划
5. `student` 登录 → 「培训」→ 看到该培训 → 打开预览/下载 ✅

### 场景 B：考试全链路
1. `admin` 登录 → 题库管理 → 新建 2 题 → 提交审核
2. 换 `rev1` 登录 → 审核：一审、二审通过
3. `admin` → 考试管理 → 新建考试（抽 APPROVED 题）→ 发布
4. `student` 登录 → 考试中心 → 进入考试 → 答题（含切屏 1 次）→ 交卷
5. `admin` → 考试记录 → 看到成绩；简答题阅卷加分
6. `nurse_head` 登录 → 成绩修正：改 `student` 分数 → 保存 → 确认状态变化 ✅

### 场景 C：成绩公示
1. 完成场景 B（学员交卷）
2. `student` → 交卷结果页/考试记录 → 看到「待公布」，无分数
3. `admin` 或 `nurse_head` → 考试管理 → 点【公布成绩】
4. `student` 刷新 → 看到分数与是否通过 ✅
5. （可选）`admin` 点【收回】→ `student` 刷新 → 分数重新隐藏 ✅

### 场景 D：补考流程
1. 完成场景 B（学员交卷，chance 已耗尽，无法再进考试）
2. `admin` 或 `nurse_head` → 考试记录 → 点【补考】→ 确认
3. `student` 刷新「在线考试」→ 可再次进入该考试 → 重考交卷 ✅
4. 考试记录中该学员保留历史成绩，最近成绩/通过状态按新成绩更新 ✅

### 场景 E：数据权限隔离
1. `rev1`（粤西）登录 → 统计看板/成绩列表 → 只看到 C01~C07 数据
2. `nurse_head`（总监）登录 → 全量数据可见
3. `student` 登录 → 只看到自己的记录 ✅

## 七、安全验收点汇总

| # | 项 | 方法 | 期望 |
|---|---|---|---|
| S1 | 越权访问 | 未登录调 `/api/...` | 401/403 |
| S2 | 角色越权 | 学员调管理端接口（如建题） | 403 |
| S3 | 数据越权 | 督导查区域外成绩 | 查不到 |
| S4 | 成绩修正 | 非总监调 `/edit-score` | 403 |
| S5 | 审核越权 | 医护长调 `/review` | 403（无权限点） |
| S6 | SQL 注入 | 搜索框输入 `' OR 1=1--` | 正常返回/被过滤，无注入 |
| S7 | XSS | 输入 `<script>` 类内容 | 被转义/存储为文本 |
| S8 | 上传安全 | 上传 `.exe/.jsp` | 被拒绝 |
| S9 | 上传覆盖 | 上传同名恶意文件 | 文件名被消毒，不覆盖 |
| S10 | 敏感信息 | 审计日志查看 | 手机号等脱敏显示 |
| S11 | 密码存储 | 查 `el_sys_user.password` | bcrypt 哈希 |
| S12 | AI 配置越权 | 非 admin 调 `/aiconfig/{view,save,test}` | 403 |
