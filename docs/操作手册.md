# 血透中心医护培训平台 · 操作手册（照着做就行）

> 打开浏览器输入：**http://localhost:8000** ，用下面的账号登录。
> 遇到"看不到某个菜单"，说明该账号没有这个权限，请换对应账号。

## 0. 登录

1. 打开 http://localhost:8000
2. 输入账号、密码、图形验证码（看不清点图片换一个）
3. 点【登录】
4. 进入后左边是菜单，中间是页面

**常用账号**：

| 账号 | 密码 | 身份 | 主要能干什么 |
|---|---|---|---|
| `admin` | <本地管理员密码> | 系统管理员 | 管账号、管系统配置 |
| `nurse_head` | <本地管理员密码> | **医护总监（你）** | 一切业务 + 改成绩 |
| `rev1` | <本地管理员密码> | 区域督导（粤西） | 审题、审批、看区域数据 |

## 1. 学员操作（student 登录）

### 1.1 参加考试
1. 左边菜单点【考试中心】→【在线考试】
2. 找到"演示考试"，点【进入考试】
3. 按提示点【开始考试】→ 出现答题卡（17 题）
4. 逐题作答：
   - 单选/多选/判断：直接点选项
   - 填空：在输入框打字
   - 简答：在文本框中写内容
5. 中途切到别的页面 = 切屏，会被记录违规；切太多次会被警告
6. 答完点右上角【交卷】→ 确认
7. 自动跳到结果页：
   - **成绩未公布时**：显示"交卷成功，成绩待管理员公布"，看不到分数
   - **成绩公布后**：显示得分、是否通过

> **注意：每场考试只有 1 次机会**，交卷后不能再进入。
> 如果因为特殊原因需要重考（例如没考及格要补考），必须联系**管理员或医护总监**在成绩记录里点【补考】。
> 成绩什么时候能看到，由**管理员决定**（他公布了你才看得到），学员自己无法提前看到分数。

### 1.2 查看历史成绩
- 【考试中心】→【考试记录】→ 看到每次考试的分和结果

### 1.3 学习培训内容
1. 左边点【培训】
2. 列表里只有**你被分配的培训**（例如"演示培训计划"的培训内容）
3. 点【预览】看内容，或点【下载】保存到本地

### 1.5 改密码
1. 右上角头像 →【个人中心】或左边【用户设置】→【密码安全】
2. 输入旧密码、新密码、确认 →【保存】

## 2. 医护总监操作（nurse_head 登录，这是你的主要账号）

### 2.1 审核题目（助理/医护长建的题要你或督导审）
1. 【题库管理】→【试题管理】
2. 看到状态为"草稿"的题，点【审核】
3. 一审【通过】→ 状态变"待二审"
4. 再点【审核】二审【通过】→ 状态变"已通过"，这题才能被抽入考试

> 你自己建的题自己可以审；**助理建的题**由你或督导审。

### 2.2 新建考试
1. 【考试管理】→【考试管理】
2. 点【添加考试】→ 填：考试名称、考试时长、及格分
3. 配组卷规则：点【添加题型规则】→ 选题型（单选/多选/判断…）、数量、每题分值
4. 点【保存】→ 考试生效，学员就能在考试中心看到

### 2.3 查看/修正学员成绩（你专属）
1. 【考试管理】→【考试记录】
2. 找到某学员成绩，点【成绩修正】
3. 输入新分数 + 原因 →【保存】
4. 分数变了，通过/未通过自动按及格分重算

> 只有你能改成绩。助理/督导/学员都改不了。

### 2.4 公布考试成绩（学员交卷后看不到分，由你说了算）
1. 【考试管理】→【考试管理】（考试列表）
2. 每个考试右侧有"成绩公示"列：
   - **待公布**：学员交卷后只能看到"交卷成功，成绩待管理员公布"，看不到分数
   - **已公布**：学员在结果页/考试记录里能看到分数和是否通过
3. 想公布时，点【公布成绩】→ 确认 → 学员立刻能看到分数
4. 想收回时，点【收回】→ 学员又看不到分数了

> 建考试时也有"交卷后公布成绩"开关（默认不公布）。
> 学员考试记录、成绩修正、补考都不受公示影响，管理端始终能看到真实成绩。

### 2.5 发起学员补考（你和管理员可以做）
1. 【考试管理】→【考试记录】
2. 找到考完的学员，点操作列【补考】
3. 确认弹窗 → 该学员的"考试次数"被重置
4. 学员刷新【在线考试】→ 可以再次【进入考试】重考

> 每场考试默认只有 1 次机会，交卷后系统会自动拦截再次进入。
> 需要重考时必须由管理员或你在这里点【补考】，学员自己无法反复考。

### 2.6 审批培训计划
1. 【培训计划】→ 看到"待审批"的计划
2. 点【通过】→ 输入意见（可空）→ 确认 → 计划生效
3. 或点【驳回】→ 填原因 → 退回给创建人

### 2.7 分配学员到培训计划（决定谁能看到培训）
1. 【培训计划】→ 找到"进行中/已结束"的计划
2. 点【分配学员】
3. 弹窗右侧"待分配学员"里点某学员的【分配】→ 该学员移到左侧"已参与学员"
4. 点【移除】可取消
5. 分配后，该学员登录就能在【培训】里看到这个计划的内容

### 2.8 看全公司数据
- 【统计看板】→【培训数据看板】：学员数、考试人次、通过率、参训名单（可看全部分中心）

## 4. 系统管理员操作（admin 登录，管系统）

### 4.1 新建账号
1. 【组织架构】→【人员管理】
2. 点【添加】→ 填账号、姓名、部门 →【保存】
3. 找到新用户，点【分配角色】→ 勾选角色（医护/医护长/小组长/助理…）→ 确认
4. 告诉对方初始密码，登录后自己改

### 4.2 管理菜单/角色
- 【系统设置】→【角色管理】：给角色勾选能看的菜单和按钮
- 【系统设置】→【菜单管理】：调整左边菜单结构
- 【系统设置】→【数据字典】：维护题型、难度等下拉选项

### 4.3 配置 AI 出题（换 AI 供应商 / 填 API Key）
1. 【系统设置】→【AI 设置】
2. 服务商下拉选模板（DeepSeek / 通义千问 / OpenAI / Kimi / 智谱 / 自定义）→ 自动填好接口地址和模型名
3. 填入该服务商的 **API Key**
4. 点【测试连接】→ 显示"连接成功"说明 Key 可用
5. 点【保存配置】→ 生效
6. 想换 AI：重新选服务商 → 填新 Key → 测试 → 保存

> 只有 admin 能改 AI 配置。Key 只保存在系统数据库里，界面不完整回显（显示为 `sk-***f0e9`）。
> AI 出题在【题库管理 → 试题管理 → AI 出题】以及培训内容上传处的 AI 出题功能里使用。

> 只有 admin 能看到【系统设置】。

## 5. 医护长操作（需要先建账号）

### 5.1 建医护长账号
1. admin 登录 →【组织架构】→【人员管理】→【添加】
2. 部门选对应中心，分配角色选【医护长】
3. 用新账号登录后，能做下面的事

### 5.2 医护长能干的事
1. 看**本科室**成绩/看板（看不到其他中心）
2. 建培训计划（但要总监/督导审批）
3. 分配本科室学员到计划
4. **不能建题**、**不能组考试**、**不能改成绩**、**看不到系统设置**
5. 自己也参加考试和学培训（有学员端）

## 7. 常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 登录提示验证码错误 | 看错/过期 | 点验证码图换一个再试 |
| 看不到某菜单 | 账号没这个权限 | 换对应角色的账号，或找 admin 分配角色 |
| 建了题但抽不到 | 没审核通过 | 找督导/总监在试题管理里审核通过 |
| 学员看不到培训 | 没被分配到计划 | 管理端培训计划→分配学员 |
| 考试点不进 | 时间没到/已结束 | 检查考试起止时间 |
| 交卷后看不到分数 | 成绩未公布 | 等管理员在考试管理点【公布成绩】 |
| 交卷后还想考 | 每场考试只有 1 次机会 | 找管理员/总监在考试记录里点【补考】 |
| 忘记密码 | — | 找 admin 在人员管理重置 |
